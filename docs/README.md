# OneQay Documentation Areas

Folder `docs/` menampung dokumentasi mendalam yang mendukung dokumen kanonis di root repository.

| Area | Isi |
|---|---|
| `architecture/` | Model konteks, container, component, dan quality attributes |
| `diagrams/` | Source diagram yang dapat direview dan dirender ulang |
| `database/` | Data dictionary, ERD, migration notes, query/performance studies |
| `api/` | Machine-readable contracts, examples, webhook/event schemas |
| `deployment/` | Runbook, environment matrix, backup/restore, DR |
| `uiux/` | Research, journey, design tokens, component/accessibility specs |
| `adr/` | Architecture Decision Records |
| `handbook/` | Completion reports, prompts, and handbook maintenance material |

Root documents remain authoritative. Detail documents must link back to their canonical owner and may not silently override an Approved decision.
