# Main Ruleset Sentinel Test

This non-substantive document exists only to verify repository-control enforcement for the `main` branch.

It does not:

- change any OneQay product decision;
- accept an ADR;
- authorize source code;
- open Phase 0 preview exit;
- complete a governance task;
- ratify PR #25 through PR #33;
- authorize release or deployment.

Expected enforcement:

- the pull request must require an independent approval;
- stale approval must be dismissed after a new push;
- required status checks must pass;
- conversations must be resolved;
- force push and direct update to `main` must remain blocked;
- no owner or administrator bypass may be available.
